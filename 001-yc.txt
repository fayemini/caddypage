闭门探讨：130位AI创业者，对Clawdbot和下一代AI产品的39条思考

Clawdbot（现在叫 OpenClaw）很火，几乎是现象级的。

帮助投资人找项目、做交易、接入飞书作为工作助手，很多人已经把 Clawdbot 玩出了花，本地 Agent、personal Agent 也成为 2026 年大家都在关注的方向。

2 月 4 日，Founder Park 搞了一场闭门活动，聚集了 130 多位 AI 创业者，来自 AI 游戏、AI Coding、Agent Memory、AI 硬件、AI 语音等不同赛道，分享了他们在上手用 Clawdbot 的感受和思考。

应用侧、技术侧、端侧、硬件，这场闭门，从各个角度全方面地拆解了 Clawdbot 到底是什么、离真正能 scale 落地的 Agent 还差什么，以及这一波可能给 AI 圈带来什么样的冲击。

Founder Park 把这场讨论中的部分精彩观点、思考、争议整理出来。对这波趋势的理解，因人而异，因不同「角度」而异。因此，以下内容更多地是「非共识」，希望能抛砖引玉，给大家带来一些新思考。

01
从被动响应到主动服务，
AI 开始自己迭代自己了
1. Agent 虽然已经很聪明了，但用户面对一个 Agent 产品时，还是很「笨拙」，不知道自己到底想干什么。

2. Clawdbot 最大的突破点是，自主权限的突破。大家给了 AI 一个非常高的自主权限。更关键的是，它对 Skill 的编辑或创造是开放的、没有边界的，为自我进化打开了想象空间。

3. Clawdbot 之所以能给大家「主动」的感觉，很大原因是它的一些内置机制，给了 Agent 更多的自主性。比如在 Moltbook 上，它会默认每 4 小时自己去探索一下「可以做些什么」。这种高频的定时任务，加上足够大的自主空间，催生了更多的可玩空间和想象力。

4. AI 的自主感知能力其实很强。过去，prompt 都是我们来写。今天，尝试让我的 Agent 自己去感知我的环境变化，包括本地文件、邮箱、云盘、日历等等，然后观察它是如何主动地感知这些变化，主动为我创造新的 Skill，然后自己调度执行，实现一些新的点。

5. Clawdbot 最核心的一点是，AI 能够迭代工具本身，这个是非常可怕的。而且现在，Clawdbot 已经成为了无可争议的开源 Agent OS 的第一名。

6. 过去一年，其实大家都没有找到一个能让 Agent self-evolve 的好场景。现在看来，个人本地 Agent 可能是最好的场景。一方面是，用户给它的任务非常多样化，迫使它必须在不同领域都做到越做越好；另一方面，它需要不断记住用户的偏好，这个「记住」的过程，本身就是一种针对特定个体的 self-evolve。

7. Clawdbot 的进化速度真的超乎想象。现在，感觉它已经进化到我们有点不认识它了。虽然还没到完全失控的地步，但说实话，已经觉得吓人了。




02
Skills 就是新时代的 Apps
8. Clawdbot 之后，可能会有一个新的机会到来。现在的 Agent 、IM 其实就是新的 OS；个人 AI 云电脑是新的 Runtime；Skills，就是新时代的 Apps。在构建这个全新的用户交互层中间，会出现大量的创业机会。

9. 过去，用户得先打开产品才能使用。现在，用户可能在数百亿流量的 IM 入口中与你的产品做交互，这个唯一能触达到你产品的点，就是那个 Skill。

10. 底层的沙箱、云电脑，以及大模型，无论是 Kimi 2.5 还是 Claude 3.5 Sonnet，都将趋于同质化，成为标配。唯一的变量就是 Skills，你的 Skill 能提供什么新的增量价值。

11. 从 2026 年开始，一个新变量会出现。以前大家做自己的 Agent，做自己的 UI 入口，未来变成了大家不需要有交互入口了。未来的模式是：开发一个 Skill，将它发布到 Skill Store，然后等待被大量的 Agent 发现、调用。

12. 产品所有的增量价值，都来自于用户在 IM 交互中激活，以及运行你的 Skill 所带来的收益。商业化的关键，不再是让用户订阅整个 App，是为每一次成功的 Skill 执行付费。

13. Skill 会成为所有平台的标准。未来，所有的人都会只会在各种 IM 中下达指令，不会关心是哪个工具在服务。所以说，未来的竞争，是围绕在如何在 Skill Store 中做好 SEO、如何优化 Skill 的交互链路，以及如何设计好其中的商业化闭环。

14. 未来绝大多数产品都会「Skill 化」，所有的 Apps 也会「Skill 化」。开发者不再需要维护 UI 界面，只需要提供能力，做好被发现、被调用的机制，以及与 Agent 和人的交互体验就可以了。




03
Memory as a File System
15. 大家都说 Agent 的 memory 是 Infra，但我个人更偏向于把它看作一个轻量化的组件。

16. Memory 其实和现在常说的 self-evolving agent 是紧密相关的。如果 Agent 能在运行中不断总结、优化自己的 Skills，它就能越做越好。从这个角度看，memory 其实就等同于 self-evolving。没有 memory，Agent 基本上就没有进化的能力。

17. 「Memory as a File System」，一定会是未来的其中一个方向。因为 Agent 天然对读上下文这件事情非常的擅长，把信息记录成 file 对它来说更友好。

18. 但未来的记忆系统不会是单一模式，最后一定是个混合的 solution。Agent 应该能自己判断，当前任务需要的是精确检索、模糊检索，还是直接去检索一个结构化的索引或文件。

19. 进化是需要反馈闭环的。Clawdbot 今天的思考还是需要人来做反馈的，否则它所有的 Skill、迭代方向是没有边界的。需要像做 RLHF 一样，不断在反馈中引导它，让它走向更符合我工作偏好的主动 Agent。我把我的所有反馈都做成 memory，让它的 Skill 在这个 memory 里去迭代进化。

20. Clawdbot 的本地文件系统不仅 Token 消耗大，召回能力也有限，因为它没有索引。这个问题要靠一个云端的、由小模型驱动的记忆引擎来解决，去帮它做推理、信息凝练、召回和过滤。所以，未来的智能体，必然是一个多智能体协作的系统。




04
人类「交互带宽」有限，
终极形态应该是 A2A 互动
21. 每一波 AI 更新出来，其实都是在圈内很嗨，但很难破圈。为什么？传统 C 端用户的日常任务和信息处理的「带宽」是有限的。

普通大众的日常是很琐碎的，可能就是「写个文案」、「问个天气」。如果一个 AI 产品要求用户有极高的「任务定义能力」，或者给用户返回一堆需要二次处理的信息，比如扔给你一个 GitHub 链接让你自己看），普通用户的「认知带宽」就溢出了。处理不过来，也缺少动机去处理。

22. 同样，「交互带宽」也是受限的。人类一直在不停地追求信息传递的速度。但点对点的信息传递，在微信这种 message app 上已经做到了头。我们的大脑处理速度，决定了我们没法实现高效的「面到面」沟通，即一万个人同时与另一万个人进行有效的三次握手。

23. 这次 Clawdbot 让人兴奋的，不是人与 AI 的互动，而是它真正做到了 AI 与 AI 互动的可能。Agent 之间可以以机器速度完成成千上万次「三次握手」，这直接放大了整个社会的信息交流效率。

24. 在「AI 与 AI 互动」这个点上，可以长出非常非常多的应用，不管是社交，还是以前这些内容社区，全都可以被重新做一遍。

25. 从 AI 的底层能力上看，人通过 Chat 去直接操纵 LLM 的这种范式是错误的。没有发挥出 AI 在「速度」上的真正优势。人慢吞吞的大脑去指挥一个高速的 AI，效率太低了。前面两年每年都有人说「狼来了」，但我觉得今年才是真正的「狼来了」。




05
未来的 AI 产品，
应该「活」在用户最高频的工作流中
26. 以前用 AI，先想到 ChatGPT、豆包这类「目的地」应用，主动去打开它。虽然 ChatGPT 周活能做到 10 亿，但始终是个有限的入口。但现在，Clawdbot 能在所有的 IM 和任何能做聊天的入口做交互。这意味着，AI 的入口，从单个 App 一下子到了能覆盖百亿甚至千亿用户。这是第一次，用户在真正意义上能以最自然、最直接的方式和 Agent 交互。

27. IM 即任务入口。能不能在 IM 里直接管理我的 To-do？现在，通过 Skill，我把滴答清单这样的应用接了进来。在聊天框里，AI 就能帮我拆解任务，自动填入清单，再同步到日历。IM 成了我任务管理的入口，让 AI 去处理，最终的 GUI 面板就是一个汇总看板。

28. 社交场景。把 Clawdbot 的执行能力和社交结合，可能会自然生长出一个全新的社交平台。想象一下，你想「找几个在北京爱打羽毛球的人」，它可能就会到网上去找各种各样的数据和 Skills 去做分析，和别人交流。甚至和其他人的 Agent 进行交流。可能会形成一个新时代的社交圈层，能大大提高大家对信息处理的效率，而且能极大拓宽普通人的动机和视野。

29. 交易场景。Clawdbot 能传播这么广，就是拿来做 trading。特别是结合了预测市场之后，比如 Polymarket 这种。这个市场比的就是手速和信息面。以前这是专业人士才能玩的，现在，推特和 GitHub 上有大量各种用 Clawdbot 搭建交易 Bot 的教程。




06
端侧可以作为，
Agent 上下文的「沉淀池」
30. 从端侧产品的角度来看，最核心的还是 Agent 本身的设计，包括模型和脚手架如何做得更好。

31. 一个思考是，端侧可以作为上下文的「沉淀池」。Clawdbot 本质上是一个效率工具，适合执行长流程任务。但我们每个人的手机、穿戴设备，其实是更重要的生活工具，和人们每天产生最直接、频繁的交互，沉淀了大量真实、细碎、但又高度个性化的上下文。




07
安全，是目前最大的短板
32. Clawdbot 现在有两个非常痛的痛点。

 一是上下文处理没有经过优化，Token 消耗非常夸张。如果不从 memory 层面进行优化，或者对 context 不做优化，这个成本其实没有人能 cover 住。

  二是低效的文件检索。Agent 在本地生成大量文件后，下次再找就很困难，因为它缺乏有效的索引机制。

33. 无论是云端还是本地，现在的沙箱和本地虚拟化 Infra 实际上都是严重不足的，无法很好地支持 Agent 的检查点和恢复这类高级功能。

34. 安全，是当前最大的短板。我恰恰认为 Clawdbot 应该部署在云端，而且必须严格限制网络访问。它现在完全不安全，需要设定很多安全规则，比如限制它只能接入公司内网，不能随意访问外部网络，因为它太容易被 hack 了。

35. Claude Cowork、Clawdbot 这类产品，目前没有一个好的备份和沙箱机制。它删你东西的时候，像一个搞不清 Git 的「新手」，只不过工程师自己能 review 和回滚。但普通用户不懂这些，碰到一个通用 Agent，出问题的频率会高得多。

08
Clawdbot，
会成为 2026 年 AI 应用的主流形态吗？
36. Clawdbot 带来了一些和聊天不一样的「增量」。它的本质，是为你配了一台「云电脑」。第一次可以真正地指挥一个 AI 去增、删、改、查文件。这让 AI 从一个信息工具，变成了一个执行工具。

37. 这次 Clawdbot 的爆火，更像是一场硅谷极客圈的内部狂欢，它反映了一个事实：大众市场仍然是缺席的。大量的 AI 应用，其实还没有真正触达到更广泛、更多元、更下沉的大众市场。

38. Clawdbot 很可能就像当年的 Linux，是一个发烧友在不设限的环境中创造出来的产品。恰恰因为它打破了这个规则，才打开了这个潘多拉魔盒。

39. 未来，Clawdbot 很可能会稳定成为一个开源操作系统。现在大家已经在上面去做生态了，后来者再去想追赶其实很难。因为它的迭代，不再仅仅依赖开发者。任何一个用户，有一个 crazy 的想法，几分钟就能让 AI 帮他写成代码、发布成 Skill。这种基于 AI 的进化速度，是传统软件开发模式无法比的。


和 30 位创业者一起聊聊，真正值得关注的 Agent 生态位在哪？
OpenClaw 把 Agent 带火了。但它真正带来的，不只是一个好用的工具，而是整个 Agent 生态，从上到下都要重做一遍的巨大机会。

支付要重做，身份要重做，权限、协议、运行时、Agent-ready 的网站、AI 协作基础设施……围绕 Agent 的一切基础设施，都要重新长出来。

对于创业者来说，最值得问的问题，不是「我能用 OpenClaw 做什么产品」，而是：在这场「重建」里，哪些生态位是真正值钱的，谁能最先占住？

所以，在第四期 AI 产品市集 Meetup 上，我们和三十多位 AI 创业者们一起聊聊：在 OpenClaw 之后，有哪些创业机会真正值得去做？

01
Token 消耗带来的不是量变，
更多是质变
质变：有时候 10 个人，不一定能干得过一个人配上 AI


AI 招聘产品创始人：

现在的重点不是一个人能干多少活，而是产生的质变：有时候 10 个人不一定能干得过一个人配上 AI。

我们在做的新产品，是关于 agent team harness 方向的。

关于 Token 消耗，我自己订了好几个服务，核心还是在用 Claude Code。我禁止团队里所有 agent 自己写代码，agent 文件里写明了不可以写代码，必须走 product 思路，用 ACP、CLI 直接调用，省去大量重复编码。

我们团队里用量最高的，一个月花了 4 万多人民币，天天在用 Cursor。但我觉得现在的重点不是一个人能干多少活，而是质变：有时候 10 个人不一定能干得过现在一个人配上 AI。

我们现在已经有了一个 agent 团队：从一只虾开始，慢慢有了 HR 虾，HR 虾帮我裁了两三只混进来的测试虾，现在每天还会自然新增一两只。再往后，软技能有了，硬技能还没有，比如 GitHub 操作、卫星图像调用、通信接口等等。这就需要买有硬技能的 API，也是我们后面想做的事。

AI 视觉创作工具创始人：

OpenClaw 是统管全局的连接器，但干活的还得是专用工具。

我们团队七八个人，只有三个正式开发，但全员都在用 Cursor，也有人用 OpenClaw。我个人目前还是把 OpenClaw 当玩具，没有正经让它承担生产任务。

我的判断是：OpenClaw 非常适合作为接收任务、分发任务的「总调度层」，但真正执行的还得靠专用工具，这样会比较稳定。

我们产品是做 AI 视觉创作的，每生成一个设计背后可能用几千到几十万 Token，一个用户一天能用到一两百万 Token，所以用量比较高。最近三天的 AWS 账单已经超过 3000 美元。

更少的 Token 消耗带来更多的价值也是一种方向
AI 创作工具创始人：

很多人不会用，导致大量的浪费。这是个 UX 问题，不是 Token 问题。

我们公司 Token 消耗非常少，因为我们在从用户体验角度研究：在 OpenClaw 出来之后，真正的普通用户怎么感受到 agentic 交互？

我们观察到，很多人不会用 OpenClaw，导致大量无效消耗。memory 看不见，skill 不知道在哪里，用户非常困惑。我们是反向的：怎么用更少的输入，带来更多的价值？这个角度，我觉得还没有人认真做。



02
支付是 agent 生态里最容易被忽视，
但最关键的基础设施
Agent 要先学会花钱才能赚钱
Agent 支付方向创业者：

传统支付平台要填 CCV、填一堆东西，这和 OpenClaw 的形态极度不匹配。

我三年前就在做 AI data agent，后来发现 agent 没有身份、不能支付，是最大的拦路虎。OpenClaw 帮你执行任务，碰到的第一个麻烦就是：它没有钱包。

现有支付平台都是订阅制，但 OpenClaw 调用 API 时希望按任务付费，不是包月，而是每次任务完成后付一次。举个例子，我要让 OpenClaw 跑一个很棒的 PPT 转场 skill，但那个 skill 需要可灵，我没开通，为了试一个 skill 得额外交一个月会员费，非常肉疼。

所以核心问题是：怎么让 OpenClaw 能快速基于任务付款、找到供给、完成交付？更进一步，如果 agent 连采购能力都没有，怎么能帮主人赚钱？先花钱才能赚钱，大公司里也是这个逻辑。

数字支付方向从业者：

如果 agent 拿到了你的信用卡号加 CVV，它可以直接把你几万美元刷掉——这不是小问题。

我们是一家服务数字业务的支付平台，从去年开始服务了大量的 AI 应用商户。

从传统支付的角度看，核心问题是身份验证，怎么 verify 这个 agent 的身份和主人的授权边界。

我们的思路是两个维度：一是权限维度，设定 agent 能在哪些场景采购；二是额度维度，对消费金额设置上限，防止 OpenClaw 一次把钱用完。

Agent 支付和身份，最大的卡点是谁来担责
Agent 知识方向产品创始人：

担责是最大的卡点——AI 帮你做事，结果由谁负责？

我们在做的是 agent 生态下知识经验的流通协议，叫 STD。基本逻辑是：一个律师从业 15 年积累的经验，网上搜不到、学校学不到；我们要做的是把这些知识经验沉淀下来，让 AI 之间可以调用、交易和流通。

关于支付和身份，我的观察是：当前最大的卡点是担责。当 AI 帮你做一件真实的事，不是简单问答，结果到底由谁负责？我们认为，提供服务时背后最好要有专家的个人背书，才能建立用户的信任。

问题不在支付本身，在于 agent 还不会交易
AI 招聘产品创始人：

Agent 可观测性 —— 监控 Agent 在干什么、花了多少钱、有没有出错（类比：Datadog 之于微服务）

Agent 记忆与状态管理 —— 让 Agent 记住上下文、跨会话协作
市场规模预测：

细分领域	2026 年市场规模	2030 年预估	年复合增长率
Agent 编排与开发框架	8 亿美元	120 亿美元	72%
Agent 可观测性	3 亿美元	45 亿美元	68%
Agent 安全管理	2 亿美元	60 亿美元	85%
Agent 记忆/状态管理	1 亿美元	25 亿美元	80%
关键玩家： LangChain、CrewAI、AutoGen、OpenClaw（开源Agent框架中增长最快的黑马）


真实案例：谁已经在赚钱？

OpenClaw 从 2025 年 11 月一个奥地利开发者用 Claude 搞出的原型，到 2026 年初 GitHub 星标飙升至 25 万+，社区市场 ClawHub 收录超 5700+ Skills，其中金融投资类 311+ 个。有 AI Bot 在 Polymarket 上一周赚了 11.5 万美元，社区用户从 50 美元滚到 2980 美元的案例被疯传[29]
高盛预测，AI Agent 将推动 2030 年应用软件市场达到 7800 亿美元，Agent 贡献 60%+ 收入[28]
2025 年 AI 领域占全球风投近 50%（2023 亿美元），同比增长 75%，其中 Agent 基础设施是最热的子赛道之一[1]
为什么说”铲子”比”金矿”更赚钱：

做大模型是军备竞赛，烧钱如流水，最终可能只剩 3-5 家。但 Agent 基础设施不一样——不管谁家的大模型赢了，都需要编排、监控、安全。 这就像当年的云计算，不管谁家的云赢了，Datadog、HashiCorp、Cloudflare 都赚到了钱。

据 Gartner 预测，至 2026 年，40% 的企业应用将集成任务型 AI Agent，而 2025 年这一比例不到 5%[33]。Gartner 的最佳情景预测：到 2035 年，Agentic AI 可驱动企业应用软件收入的 30%，超过 4500 亿美元[33]。

但也有血的教训： 2026 年 2 月，OpenClaw 社区曝出 ClawHavoc 投毒事件——1184 个恶意 Skills 被上传到官方市场，伪装成正常工具窃取用户 API 密钥和钱包私钥[30]。基础设施赛道的安全问题，就是下一个创业机会。

普通创业者的切入点：

针对某个垂直行业做 Agent 工作流模板（比如：电商客服 Agent 解决方案）
做 Agent 的测试与评估工具
做 Agent 的成本优化工具（Token 用量监控 + 智能路由）
赛道二：AI + 企业工作流自动化（规模最大）




一句话概括： 不是给企业一个聊天框，而是直接帮企业把活干了。

核心逻辑：

过去两年，无数企业买了 AI 产品，然后发现——用不起来。 员工不知道怎么写 Prompt，领导不知道怎么衡量 ROI，IT 不知道怎么跟现有系统集成。


麦肯锡 2025 年调查显示，88% 的企业已在至少一个业务部门使用 AI，但只有三分之一实现了规模化部署[21]。92% 的企业计划在未来三年增加 AI 投入，但只有 1% 的领导者认为自己公司在 AI 部署上达到”成熟”水平[34]。2025 年企业 AI 工作流自动化项目的平均 ROI 达 171%，62% 的项目回报超过 100%[22]。

真正赚钱的不是”卖 AI 工具”，而是用 AI 重新设计企业的工作流程，让效率提升 5-10 倍。麦肯锡最新研究表明，高绩效企业的共同点是从根本上重新设计个人工作流，这些企业实现商业影响的概率是其他企业的 3 倍[34]。

真实案例：AI 工作流已经在赚大钱

麦肯锡调查显示，2025 年企业 AI 工作流自动化项目的平均 ROI 达 171%，62% 的项目回报超过 100%[22]
英矽智能用 AI 将药物发现周期从 4.5 年缩短至 18 个月，研发成本降低数十倍[4]
国内某头部电商用 AI 客服系统，单日处理工单 50 万+，人工客服团队缩减 60%，年省成本超 3000 万元
已经被验证的高价值场景：

场景	传统方式耗时	AI 自动化后	效率提升	企业年付费意愿
合同审查	律师 4-6 小时/份	AI 15 分钟初审 + 律师 30 分钟复核	8x	50-200 万美元

这个赛道的核心壁垒是什么？

不是技术，是行业理解。

你得真正理解一个行业的工作流程——哪些环节是瓶颈、哪些决策有风险、哪些数据可以打通。这不是一个技术团队闭门造车能搞定的，需要行业老兵 + AI 工程师的组合。

麦肯锡强调，高绩效企业的共同点是将 AI 投入超过数字化预算的 20%，并且几乎全部都在”重新设计工作流”而非简单”叠加 AI 功能”[21]。

收入模型的优势：

这个赛道最美妙的地方在于：客户一旦用上，就很难迁走。 因为 AI 工作流跟企业的 ERP、CRM、OA 深度集成，切换成本极高。这意味着：

高续费率（>90%）
可以按”节省成本的百分比”收费，而不是按功能收费
年合同金额通常 50 万美元起步
中国市场的落地验证： 零一万物发布的”万智 2.5”企业级多智能体平台证明，多 Agent 协作可完成原需十人团队的复杂工作流[34]。某 500 强央企利用知识图谱赋能 10 万+员工，检索效率提升 30%；某手机制造商推动 4 万+员工办公 AI 化，流程效率提升 50%[34]。2026 年正在成为”多智能体上岗元年“[34]。

赛道三：AI 编程与开发者工具（增速最快）
一句话概括： 程序员不会失业，但不用 AI 编程的程序员会失业。


现状：

2026 年初的数据显示：

GitHub Copilot 付费用户突破 2000 万，被 90% 的财富 100 强企业采用[23]
Cursor 年化收入突破 20 亿美元，估值达 293 亿美元，在 24 个月内从 100 万美元收入飙升至 10 亿美元——过去 3 个月收入翻倍[35]
Claude Code 在专业开发者中的渗透率持续攀升，与 Copilot、Cursor 合计占据 70%+ 市场份额[23]
超过 46% 的新代码已经由 AI 辅助生成[23]
国内知乎横评显示，Cursor 日活突破 500 万，Claude Code 在长链条逻辑推理和跨层依赖处理上领先[11]
a16z（Andreessen Horowitz）将 AI 编程称为“万亿美元赛道”：全球约 3000 万开发者，每人每年创造约 10 万美元经济价值，总可寻址市场（TAM）高达 3 万亿美元[24]。竞争之激烈可见一斑——Google 斥资 24 亿美元收购 Windsurf，击败 OpenAI[24]。微软和 Google 的 CEO 都声称各自公司约 25% 的代码已由 AI 生成[24]。

MIT Technology Review 更是将“生成式编程”列为 2026 年十大突破技术之一[25]。但硬币的另一面是：斯坦福研究发现，22-25 岁软件开发者的就业率在 2022-2025 年间下降了近 20%[25]。GitClear 数据显示，自 2022 年以来代码复制粘贴量增长了 4 倍，48% 的 AI 生成代码包含安全漏洞[25]。

但这才是开始。未来 5 年的增长空间在哪？

AI 编程工具市场在 2025 年达到 73.7 亿美元，预计到 2032 年增长至 301 亿美元，CAGR 为 27.1%[23]。当前工具还停留在”辅助写代码”阶段。接下来的进化方向是：

从写代码到做系统 —— AI 不只是补全几行代码，而是理解整个系统架构，自动完成跨文件的重构和功能开发
从程序员到全民 —— 非技术人员用自然语言描述需求，AI 直接生成可运行的应用
从开发到全生命周期 —— AI 覆盖需求分析、设计、编码、测试、部署、运维的全链条
Gartner 预测，到 2028 年 90% 的企业软件工程师将使用 AI 编程助手，而 2024 年初这一比例不到 14%[23]。

最值得关注的方向：

垂直领域的 AI 编程工具 —— 比如专门针对数据分析、智能合约、嵌入式开发的 AI 编程助手
AI 代码审查与安全扫描 —— 代码写得越快，安全隐患越多，这是刚需
AI 测试生成 —— 自动生成单元测试、集成测试、端到端测试
残酷现实： 这条赛道看似门槛低，实则赢家通吃。36氪分析指出，字节 Trae、阿里通义灵码等巨头以免费策略抢占市场，AI 编程已经变成”大佬的牌桌”[3]。小团队想在这条赛道活下来，必须找到巨头看不上的垂直切口。

赛道四：AI + 医疗健康（天花板最高）

一句话概括： 唯一一个万亿级别的 AI 应用市场，没有之一。

为什么医疗 AI 之前一直”雷声大雨点小”？

三个原因：

监管严格，审批周期长
数据隐私问题复杂
早期 AI 的准确率不够用于临床决策
为什么接下来 5 年会爆发？

因为以上三个障碍，在 2025-2026 年同时出现了转折：

监管破冰：FDA 在 2025 年批准了 295 个 AI/ML 医疗设备（截至 2025 年 7 月累计超过 1250 个），96%+ 通过 510(k) 快速路径，FDA 甚至在内部启动了”Agentic AI Challenge”[26]。中国 NMPA 也在 2026 年推出了”AI 医疗产品绿色通道”
隐私计算成熟： 联邦学习、可信执行环境等技术让”数据不出院、模型到处跑”成为可能
大模型准确率达到临床标准： GPT-5 和 Claude 在多项医学考试中的得分已经超过 90% 的执业医师
最赚钱的细分方向：

据多家研究机构预测，AI 制药市场将从 2025 年的 17-26 亿美元 增长至 2030 年的 80-100 亿美元，CAGR 超过 25%[25]。2025 年 AI 生物技术融资反弹至 67 亿美元[36]。礼来与英伟达宣布投入 10 亿美元建立 AI 药物研发联合实验室[37]，AI 制药初创公司 Chai Discovery 估值达 13 亿美元并与礼来达成合作[38]。

一个关键信号：

2025-2026 年，AI 制药领域的并购金额暴增。机器学习在 AI 制药中的市场份额达到 66%，而新分子设计（de novo drug design）以 27.9% 的 CAGR 成为增长最快的子领域[25]。大玩家已经用真金白银验证了这个方向的价值。

里程碑事件： 人民网报道，英矽智能的 Rentosertib 成为全球首款 AI 原创药物，从靶点发现到 IIa 期临床仅用 18 个月（传统的 1/3），成本降至传统的 1⁄10[36]。2026 年初，工信部等八部门联合提出建设 AI 驱动的新药发现平台[36]。中国 AI 制药市场从 2019 年的 0.7 亿元增至 2024 年的 7.3 亿元（CAGR 47.8%），预计 2028 年达 58.6 亿元（CAGR 68.3%）[36]。

从更大图景看，弗若斯特沙利文预测中国 AI 医疗市场将从 2023 年的 88 亿元增长至 2033 年的 3157 亿元（CAGR 43.1%）[37]。AI 医学影像领域 2026 年市场规模将增至 235.7 亿元[37]。国家卫健委等五部门已明确：2027 年建立高质量医疗数据集，2030 年基层诊疗智能辅助全覆盖[37]。

赛道五：AI + 教育与人才培训（被严重低估）

一句话概括： AI 时代最大的瓶颈不是技术，是人。谁解决”人”的问题，谁就赚大钱。

被低估的原因：

教育赛道在中国因为”双减”政策而被很多投资人直接跳过。但 AI 教育和 K12 学科辅导是完全不同的东西。

据中国市场数据，2025 年中国 AI + 教育市场规模已超 700 亿元，预计 2030 年达到近 3000 亿元，复合增速达 47%[3]。截至 2025 年底，57.3% 的中国家长在辅导孩子时使用生成式 AI 应用[3]。

三个正在爆发的方向：

1. 企业 AI 培训（B 端，客单价最高）
每家企业都在喊”全员 AI 化”，但 95% 的员工连 Prompt 都写不好。

市场现状： 2026 年企业 AI 培训市场约 50 亿美元，预计 2030 年达到 300 亿美元
商业模式： 企业内训（5-20 万美元/次）、AI 技能认证体系、在线训练营
核心壁垒： 不是教”怎么用 ChatGPT”，而是教”怎么用 AI 重新设计工作流程”
2. AI 个性化学习平台（C 端，用户量最大）
想象一个 AI 家教：了解你的知识盲区、按照你的学习节奏教学、用你最容易理解的方式解释概念、24 小时随时答疑。

技术突破点： 大模型 + 知识图谱 + 自适应学习算法
已验证的数据： 哈佛大学一项严格的随机对照试验（194 名学生）表明，使用 AI 导师的学生学习效果翻倍，同时耗时减少 20%，参与度和动机显著提高[27]。但设计至关重要——另一项研究显示，简单使用 ChatGPT 辅助数学学习反而降低了成绩[27]
合规路径： 定位为”学习工具”而非”学科培训”，避开监管红线
市场信号： 教育类 AI 产品的付费转化率达 8-15%，是通用 AI 工具的 2-5 倍[3]
3. AI 技能培训平台（面向个人，增长最快）
“如何用 AI 做 XX” 已经成为全网搜索量增长最快的关键词之一。

Prompt Engineering 课程
AI 工具实战训练营
AI + 行业技能认证（AI + 财务、AI + 法务、AI + 营销……）
全球市场加速： Precedence Research 数据显示，全球 AI 教育市场 2026 年达 95.8 亿美元，预计 2035 年飙升至 1367.9 亿美元（CAGR 34.52%）[28]。在 2024-2025 学年，85% 的教师和 86% 的学生已在使用 AI[28]。韩国在 2024-2026 年间投资约 7.4 亿美元用于教师 AI 技能培训[28]。

中国市场的独特优势： 中国生成式 AI 用户规模已达 6.02 亿（普及率 42.8%）[38]。国内智能学习机渗透率 2025 年突破 40%，AI 智能备课系统渗透率将从 2025 年的 28% 提升至 2030 年的 65%[38]。亚太地区 AI 教育复合增长率 44.2% 领跑全球[38]。

关键洞察： AI 教育的本质不是教技术，而是帮人建立新的工作方式。谁能把”AI 能力”翻译成”业务能力”，谁就掌握了这个赛道的钥匙。

赛道六：AI 安全与合规（刚需中的刚需）

一句话概括： AI 越强大，安全问题越严峻。这是一个”不得不买”的市场。

为什么说是刚需中的刚需？

欧盟 AI Act 已经生效，2026 年 8 月高风险 AI 系统必须完成合规认证，违规罚款最高可达全球营收的 7%（最高 3500 万欧元）[26]
中国新修订《网络安全法》2026 年 1 月 1 日施行，AI 相关罚款最高一千万元人民币[4]。中央网信办专家解读指出，此次修改专门新增人工智能安全条款[12]
Gartner 预测，AI 治理支出 2026 年将达 4.92 亿美元，到 2030 年超过 10 亿美元；届时碎片化的 AI 监管将扩展到全球 75% 的经济体[39]
没有合规就没有商用，这是硬性门槛
最赚钱的细分方向：

方向	客户	客单价	核心价值
AI 模型红队测试	AI 公司	20-100 万美元/次	发现模型漏洞
AI 内容安全审核	平台型企业	50-200 万美元/年	合规运营
AI 数据隐私保护	所有使用 AI 的企业	30-150 万美元/年	防止数据泄露
AI 决策可解释性	金融、医疗、法律	50-300 万美元/年	监管要求
AI 水印与溯源	内容平台、媒体	10-50 万美元/年	深度伪造防御
这个赛道的独特优势：

逆周期：经济越差，企业越不敢冒合规风险，安全预算反而增加
强制性：不是”要不要买”的问题，而是”不买就不能上线”
高粘性：安全产品一旦部署，替换成本极高
最近的标志性事件： OpenClaw 社区曝出的 “ClawJacked” 安全漏洞，直接引发了整个 AI Agent 行业对安全问题的关注。粤港澳大湾区实验室发布的《2026 AI 安全十大趋势》指出，中美欧三大治理框架均以”可审计、可问责“为核心要求[4]。TechCrunch 报道，VC 正大举押注 AI 安全赛道，”影子 AI”和”流氓 Agent”成为企业安全新痛点[40]。Gartner 将 AI 安全平台列为 2026 年十大战略技术趋势之一[41]。

赛道七：AI + 机器人/具身智能（长期最性感）
一句话概括： 当 AI 从”虚拟世界”走进”物理世界”，一切都变了。

为什么放在最后？

因为这是一个 5 年窗口期 的赛道——前 2 年主要是技术验证和试点，后 3 年才是规模化爆发。但一旦爆发，规模将远超所有纯软件赛道。

关键突破：

2025-2026 年发生了几件改变格局的大事：

大模型 + 机器人的技术路线被验证可行：机器人不再需要针对每个任务单独编程，而是通过大模型理解自然语言指令
人形机器人成本快速下降：宇树科技最新 R1 售价仅 5,900 美元，G1 售价 13,560 美元，远低于特斯拉 Optimus 预估的 20,000+ 美元[27]
中国主导市场： 中国企业控制了人形机器人 90% 的市场份额，宇树科技 2025 年售出 5,500 台，全球第一[27]。中国已投入超过 100 亿美元政府资金推动成本下降和市场统治[42]
资本疯抢： 银河通用（Galbot）融资超 3 亿美元、估值 30 亿美元；宇树科技 C 轮后估值 30 亿美元，剑指 70 亿美元 IPO[42]
据 IDC 预测，2026 年中国具身智能机器人用户支出将超 110 亿美元，保持近 120% 的高速增长[5]。36氪研究院数据显示，中国具身智能市场有望在 2026 年突破万亿元关口[6]。澎湃新闻指出，2026 年将成为人形机器人企业的商业化“大考年”[13]。

创业者的机会在哪？

不要去做机器人本体（那是硬件巨头的战场），而是做：

具身智能的”大脑” —— 针对特定场景的 AI 控制算法
机器人的”技能商店” —— 让机器人可以下载新技能（类比 App Store）
数据与仿真平台 —— 在虚拟环境中训练机器人，降低真实世界试错成本
2025 年前 11 个月，中国具身智能产业融资额达到 334.73 亿元，是 2024 年同期的 4 倍[6]。

血泪教训：AI 赛道的 6 大踩坑警示

看完 7 大赛道，你可能已经热血沸腾了。但在你冲进去之前，我必须泼一盆冷水。以下每一条，都有人付出了真金白银的代价。

坑 1：把”回测收益”当”真实收益”
OpenClaw 社区里有人用量化回测跑出了年化 59% 的收益率，各大平台争相转载。但真相是：回测数据不考虑交易成本、滑点、流动性冲击和市场结构变化。Polymarket 上只有 30% 的钱包是盈利的[31]。实盘收益通常只有回测的 1⁄3 到 1/5。

坑 2：迷信”AI 概念”，忽略商业本质
2025-2026 年，大量创业者的商业计划书只有三步：1）套一个大模型 API；2）做一个漂亮的前端；3）融资。这种”AI 壳公司”正在批量死亡。MIT Sloan 管理评论明确指出，2026 年将是”价值实现”定义赢家的一年，而非”技术实验”[28]。没有行业 know-how 的 AI 创业，本质上就是在卖铲子的矿区里再开一家铲子铺。

坑 3：低估合规成本，高估上线速度
欧盟 AI Act 2026 年 8 月高风险系统合规截止，违规罚款最高全球营收 7%[26]。中国新修订《网络安全法》AI 相关罚款最高一千万元[4]。很多团队在产品做到 80% 才发现：剩下 20% 的合规工作，要花掉和开发一样多的时间和钱。

坑 4：安全漏洞 = 一夜归零
ClawHavoc 事件不是孤例。任何涉及资金操作的 AI Agent，都面临供应链投毒、提示词注入、权限越界三重风险。 一个恶意 Skill 就能把你的 API Key 和钱包私钥全部偷走[30]。在 AI Agent 领域，安全不是”锦上添花”，而是”没有就别上线”。

坑 5：幸存者偏差让你误判市场
你看到 Cursor 从 0 到 10 亿美元，但你看不到同期倒下的数百家 AI 编程创业公司。你看到 OpenClaw Bot 一周赚 11.5 万美元，但你看不到更多人赔光本金的账户。2025 年中国 AI 应用领域 930 家公司获得 1070 亿元融资[8]，但其中能活过 3 年的可能不到 10%。2026 年 2 月全球 VC 单月投出 1890 亿美元，其中 AI 占 90%（1710 亿美元），但仅 OpenAI、Anthropic、Waymo 三家就吃掉了三分之一[43]。资金越集中于头部，中小玩家的生存空间就越窄。

坑 6：”全民 AI” ≠ “全民赚钱”
腾讯云 99 元/年的 OpenClaw 服务、百度 0.01 元尝鲜价，让人人都能跑起一个 AI Agent。但工具的民主化不等于收益的民主化。当所有人都能用同样的工具、跑同样的策略时，超额收益就消失了。真正赚钱的，永远是那些有独特数据源、独特行业理解、或独特执行能力的人。

核心原则：AI 是放大器，不是创造器。它能把你的优势放大 10 倍，也能把你的错误放大 10 倍。没有优势的人，用再好的 AI 工具也赚不到钱。
最后，给不同身份的人三条具体建议
如果你是创业者：
优先看赛道一（Agent 基础设施）和赛道二（工作流自动化）。 这两个赛道确定性最高、爆发最快、且不需要你去做大模型。找一个你熟悉的行业，深扎进去，用 AI 帮企业把效率提升 10 倍。据铅笔道报道，2026 年可能是成为 AI 头部公司”上车”的最后一年[7]。

具体行动清单：

选定一个你有 3 年以上经验的行业，列出 Top 5 重复性最高的工作流
用 OpenClaw / Claude Code / GPT 搭一个 MVP，先解决一个痛点
找 3 个真实客户免费试用 2 周，看他们愿不愿意付费
如果有人愿意付钱 → 恭喜你找到了 PMF。如果没人愿意 → 换一个痛点重来
千万别一上来就融资、招人、搞平台，先证明单点价值
如果你是打工人：
立刻学习赛道三（AI 编程）和赛道五（AI 技能）相关的能力。 未来 5 年，”会用 AI”将从加分项变成必备项。OECD 报告指出，90%+ 全球企业 2026 年前将面临 AI 人才严重短缺，技能缺口风险金额达 5.5 万亿美元[23]。现在投入 100 小时系统学习 AI 工具，你的职场竞争力会提升一个量级。

具体行动清单：

本周就开始用 AI 工具辅助日常工作（Cursor、Claude、ChatGPT 任选一个）
每天记录一个”AI 帮我节省了多少时间”的案例
一个月后，把这些案例整理成一份报告，向领导展示你的 AI 能力
不是让你转行，而是让 AI 成为你现有技能的 10 倍放大器
如果你是投资人：
短期看赛道六（安全合规），中期看赛道三和赛道四，长期看赛道七（具身智能）。 安全合规是现在就有确定性收入的方向；编程工具和医疗 AI 正在进入 PMF 验证期；具身智能是 5 年后回头看会后悔没投的方向。据统计，2025 年中国 AI 应用领域共有 930 家公司获得总计 1070 亿元融资[8]。

风险提示：

警惕”AI 概念股”泡沫——很多公司只是把现有产品贴上 AI 标签
关注团队是否有行业经验 + AI 能力的交叉背景，纯技术团队或纯行业团队都很难赢
2025 年 AI 占全球风投近 50%（2023 亿美元），五家公司就吃掉了 840 亿美元[1]——头部效应极其明显，投早期项目要做好 90% 归零的心理准备
写在最后
AI 行业现在很像 2008 年的移动互联网。

那时候，最赚钱的不是做手机的（诺基亚很快就倒了），不是做操作系统的（只剩 iOS 和 Android），而是在移动互联网上做应用和服务的那批人——微信、滴滴、美团、抖音。

AI 时代也一样。大模型是基础设施，真正的金矿在应用层。

但和移动互联网不同的是，AI 的应用不是”做一个 App”那么简单。它需要你真正理解一个行业的痛点，然后用 AI 重新设计解决方案。

这是一个属于”行业专家 + AI 能力”的时代。

纯技术人员会发现，不懂行业就无法落地；纯行业人员会发现，不懂 AI 就会被淘汰。两种能力的交叉点，就是未来 5 年最大的财富密码。
